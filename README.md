# 📒 Contact Book Using Python Dictionaries

A simple **command-line Contact Book** built using Python dictionaries.  
This project allows users to add, search, update, delete, and view contact information.

## 📌 Project Description

The Contact Book is a beginner-friendly Python project designed to demonstrate how dictionaries can be used for practical key-value data management.

Users can manage contact details such as:

- Contact ID
- Name
- Phone Number
- Email Address

## 🎯 Objective

The main objective of this project is to learn:

- Python dictionaries
- Key-value data management
- Functions
- Conditional statements
- Loops
- CRUD operations
- User input validation

## 🛠️ Technologies Used

- **Python 3**
- **Dictionary**
- **Command Line / Terminal**

## ✨ Features

- ➕ Add a new contact
- 🔍 Search for a contact
- ✏️ Update contact information
- 🗑️ Delete a contact
- 📋 View all contacts
- ⚠️ Prevent duplicate Contact IDs
- 🚪 Exit the application

## 🔄 CRUD Operations

| Operation | Description |
|-----------|-------------|
| Create | Add a new contact |
| Read | Search or view contacts |
| Update | Modify existing contact details |
| Delete | Remove a contact |
